# Changelog

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Reproducible clean-and-changed integrity demo executed by CI.
- Structured bug, feature, and pull request templates.
- Security reporting guidance and a public v1.1.0 roadmap issue.

## [1.0.0] - 2026-10-09

### Added

- SHA-256 manifest creation with atomic writes.
- Verification for changed, missing, added, and unreadable files.
- Human-readable and JSON reports with meaningful exit codes.
- Automated tests and a Python-version CI matrix.
- Contributor, safety, and usage documentation.
